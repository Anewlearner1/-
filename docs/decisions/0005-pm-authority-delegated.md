# ADR 0005: 使用者把專案管理決策權授權給團隊

- 狀態：**已決定**（2026-10-07，使用者裁示：「PM 我全部授權給你，除了需要付費的項目先找我確認，剩下的交給你們團隊討論及決策」）
- 影響：所有之後的排程、技術取捨、推送時機。

## 決定

團隊（主助理代理 product-manager 角色，與各工程角色）可以自行決定並執行：

- 里程碑順序、任務指派、技術方案的取捨與實驗設計；
- 何時 commit 與推送到 `rally-ai` 分支（不再每次等「推上去」）；
- 文件、ADR、狀態快照的更新。

## 仍必須先問使用者的事

1. **任何需要付費的項目**：雲端 GPU、付費 API、付費資料集、付費服務或訂閱、網域、任何會產生帳單的設定。
2. 授權範圍以外、本來就屬於擁有者的事（沿用既有約束）：
   - 影片與截圖**不得** commit 進公開 repo（有版權與可辨識人物）；
   - 不建立 PR、不推到 `rally-ai` 以外的分支；
   - 對外公開發布、改變授權（LICENSE 的 AGPL-3.0 全文替換屬於落實 ADR 0001，可以做，但要逐字取自 gnu.org，不憑記憶）；
   - 使用者的 email 只用於 git 作者資訊。
3. 需要使用者本人才能提供的東西：新影片、標註確認、第二位標註者。這些仍會提出請求，但不會因此卡住其他工作。

## 運作方式

- 每個重要決定都寫進 `docs/status.md` 或新的 ADR，附理由，使用者可隨時推翻。
- 驗收門檻（ADR 0002、0003）**不得由團隊自行放寬**；那是使用者訂的標準，改動仍需使用者同意。
