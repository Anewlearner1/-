# ADR 0002: 驗收門檻與發球範圍

- 狀態：**已決定**（2026-10-07，使用者裁示）
- 相關：`docs/technical-plan.md` §6（驗收標準）、`docs/status.md` §5、`docs/domain-standards.md` §3

## 決定

1. **M2（擊球數）驗收**：在**至少 10 支沒有用來調參數的合規格素材**上，以一對一配對、±10 幀容差，**擊球精確率 ≥ 0.90 且召回率 ≥ 0.90**。
2. **M3（正反拍）驗收**：在已被正確定位的擊球上，**正反拍正確率 ≥ 0.85**。
3. **發球 / 高壓球不納入 M3 統計**：分類器對這類擊球輸出 `other`（儀表板顯示「不適用」），不計入正反拍準確率，也不要求為發球蒐集標註。發球統計可日後獨立成一個項目。
4. **M4、M5** 在能夠量測之前不定數字。
5. 目前沒有特別指定要測的場景。

## 釐清（PM 補充，避免日後移動球門）

- **「合規格素材」**：≥ 60 fps、固定腳架、底線後方、純回合片段（`docs/technical-plan.md` §5）。目前已標註的 3 支側面練習片**不是**合規格素材，因此**不計入驗收**，只作開發期參考。
- **「沒有用來調參數」**：任何門檻、窗口、顏色範圍只能在別的影片上調整；驗收組不得用來選擇設定。
- **配對規則**：沿用 `ml/eval_shot_timing.py` 的一對一貪婪配對，一次揮拍的重複事件算誤報。
- **召回率的定義**：以使用者**完整標註**的擊球為分母。標註一律用燒入解碼器幀號、逐幀的截圖（見 `docs/real-footage-findings.md` 的教訓），不得使用播放器幀號。
- **標註者**：目前只有使用者一人。建議至少 5 支驗收影片由第二位標註者獨立標註，以量測一致性；尚未決定。
- 這些數字是產品判斷，隨使用者對產品定位的調整可再開新的 ADR 修改，但**不得在看到結果之後才調整**。

## 目前離達標多遠（對照 2026-10-07 的量測，僅供參考，**不是驗收結果**）

3 支非合規格練習片、22 個已確認擊球：只靠姿態 0.52 / 1.00；球色過濾 + 合併 0.5 秒 1.00 / 0.82（Fed 2 單獨 0.91 / 0.77）。召回率尚未達 0.90，且樣本與素材都不合驗收條件。
