# 驗收影片拍攝規格（給使用者照著拍）

- 版本：2026-10-07，PM 依 ADR 0005 授權撰寫
- 依據：ADR 0002（驗收門檻與「合規格素材」定義）、ADR 0003（容差 ±0.33 秒）、ADR 0004（球員須夠大）
- 用途：只有符合這份規格、**且沒被用來調參數**的影片，才能算 M2（擊球偵測）與 M3（正反拍）的**驗收**結果。目前已標註的 7 支影片都不符合，只當開發參考。

## 1. 必要條件（缺一項就不算驗收素材）

| 項目 | 要求 | 為什麼 |
|---|---|---|
| 幀率 | **≥ 60 fps**（手機設定成「1080p 60fps」或「4K 60fps」） | ADR 0002；30 fps 時擊球瞬間只有 1–2 幀，容差 ±0.33 秒也只有 10 幀 |
| 機位 | **固定腳架，放在底線後方**，高度約 1–2 公尺，鏡頭可略往下但**不要大角度俯拍** | ADR 0002；3D 正反手判斷只在大致水平的鏡頭上測過 |
| 球員大小 | 被分析的球員在畫面中**至少佔畫面高度的 1/4** | ADR 0004：球員太小時姿態偵測失效（球員佔 14% 時 5 張只抓到 1 張；20% 以上時接近 100%）。可以把腳架放近一點，或用變焦 |
| 內容 | **真實回合或餵球練習，正手和反手都要有**（每支至少各 3 拍） | 目前 7 支裡有 5 支只有一種球路，無法公平量正反拍 |
| 剪接 | **不剪接、不慢動作、不加字幕或濾鏡**，一鏡到底 | 剪接會被當成鏡頭晃動，也會打斷追蹤 |
| 長度 | 每支 **20–90 秒** | 太短拍數不夠；太長標註負擔太重 |
| 畫面中的人 | 被分析的球員從頭到腳都在畫面內；旁邊盡量不要有其他人走動 | 球員選擇目前是「最大／最中間的人」 |
| 持拍手 | 每支影片記下球員是**右手或左手** | 分類需要持拍手（上傳時選） |

### 建議（不影響 M2/M3 驗收，但之後 M4 落點／球速需要）

- 盡量讓**球場四個角都入鏡**（底線後方稍高一點、廣角）。目前手上沒有任何四角都入鏡的畫面，球場四角偵測因此無法驗證、暫緩開發；這批影片若有，就能開始做。前提是球員仍至少佔畫面高度 1/4，兩者衝突時以球員大小為優先。

## 2. 數量與組成

- **至少 10 支**（ADR 0002）。建議 12 支，留 2 支備用，萬一有不合格的。
- 最好來自**至少 3 次不同的練習／不同天**（光線、衣服不同），避免全部同一個場景。
- **如果可以，其中 2 支是左手球員**。沒有也可以驗收，但左手的判斷就只能標「未驗證」。
- 發球、高壓球不計入（ADR 0002），影片裡有也沒關係，標註時標成「其他」即可。

## 3. 標註怎麼做（在你自己的電腦上用標註頁）

1. 把影片放進影片資料夾（`RALLY_VIDEO_DIR`，例如 `C:\rally-videos`），檔名用英數字（例如 `acc01_right.mp4`）。
2. 執行 `python -m labeling.label_server`，用 Chrome／Edge 開 `http://localhost:8001/`（細節見 `labeling/README.md`）。
3. 選影片，用 ←／→ 一幀一幀看，在**球拍碰到球的那一幀**按 `F`（正手）、`B`（反手）或 `O`（其他，如發球）。
4. 標註頁顯示的是**程式解碼器的幀號**（每一幀上都燒了條碼，頁面直接從畫面讀），不會再有播放器與程式差 3 幀的問題（2026-10-07 在真實影片 Fed 1 上驗證：跳到 578／579／577／645／129 全部一致）。
5. 標註要**完整**：從頭看到尾、每一拍都標，最後勾「我已從頭看到尾，所有擊球都標了」再儲存，否則算不出召回率。
6. 若找得到第二位標註者，建議其中 5 支由他獨立再標一次，量測標註一致性（ADR 0002 建議，未強制）。

## 4. 不可以做的事（避免驗收作弊）

- 驗收影片在跑驗收之前，**團隊不會看它的結果來調任何門檻或參數**；所有門檻在拿到影片前就凍結（記錄當下的 git commit）。
- 跑完驗收後若要改程式再測，必須換一批新的驗收影片，舊的那批降為開發素材。
- 驗收門檻（M2 精確率與召回率 ≥ 0.90；M3 ≥ 0.85）由使用者訂定，團隊不得放寬（ADR 0005）。

## 5. 隱私與版權

- 影片含可辨識的人：拍別人之前請先徵得同意。
- 影片**不會**被 commit 進公開 repo（`.gitignore` 已擋），標註檔只存幀號與標籤。
- 只用你自己拍的影片；網路上的轉播或精華片有版權，也不符合規格。

## 6. 拍攝前的 30 秒檢查清單

- [ ] 手機設成 60 fps
- [ ] 腳架在底線後方，鏡頭水平
- [ ] 球員從頭到腳在畫面內，且至少佔畫面高度 1/4
- [ ] 不剪接、不慢動作
- [ ] 會有正手也會有反手
- [ ] 記下持拍手
