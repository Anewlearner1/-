- 凍結日期：2026-10-07（PM 依 ADR 0005；在任何驗收影片進來之前）
- 凍結內容：`ml/acceptance.py` 的 `FROZEN`（以下逐項列出）。驗收程式每次執行都會比對程式裡的實際數值，**有任何一項不同就判為 INVALID**，不會給出 PASS/FAIL。
- 依據：`docs/acceptance-footage-spec.md` §4（驗收前凍結、不得看結果調參）、ADR 0002（門檻）、ADR 0003（容差）。

## 怎麼跑

```powershell
python -m ml.acceptance labeling\labels\acc*.json --videos-dir C:\rally-videos
```

只有「標註完整、解碼器幀號、有持拍手、影片通過 60 fps」的影片才算數；其他會列在 EXCLUDED 並寫明原因。M2 是所有合格影片合併計算；M3 只算偵測器有找到的正反手擊球（發球／高壓不算）。

## 規則

- 驗收跑完之後如果要改任何凍結值，必須：(1) 在這份文件記下改了什麼、為什麼；(2) 更新 `FROZEN`；(3) 這批驗收影片降為開發素材，**換一批新影片**重新驗收。
- 2026-10-07 在開發影片上試跑（不算驗收）：7 支全部因不合格被排除；強制讓 Fed 1 參加時程式正常跑完（精確率 1.00、召回率 0.80、正反手 3/4），與先前量測一致。
